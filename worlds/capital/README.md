## 获取原地图

1. 打开 [Planet Minecraft 原作者页面](https://www.planetminecraft.com/project/island-moonlight-fantasy-build-download/) 并经其发布入口下载。
2. 在受控的本地目录保存原始归档，不改变原文件；记录 SHA256、下载时间和原许可页面。
3. 解压后确认存在合法 Minecraft 存档结构，例如 <code>level.dat</code> 与 <code>region/</code>；多层压缩文件夹应检查正确的存档根目录。
4. **不要直接放到生产服务器**；先在对应旧版本隔离实例中验证。
