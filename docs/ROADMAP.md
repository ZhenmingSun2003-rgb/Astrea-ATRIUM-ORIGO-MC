# ORIGO — 发行路线 / Mod 优化政策

## 版本节奏

| 阶段 | 工作重心 | 验收方式 |
| --- | --- | --- |
| v0.1.0 Visual Foundation | 三套视觉方案、固定依赖、导入包构建、中文文档、主城出处 | 结构完整，离线单元测试，联网构建（如网络可用）；实机待验 |

| v1.0 Launch | 深圳 ATRIUM 运行集成与上线 | 服务/网络隔离、备份恢复、运营监测 |

## Mod 合入规则

1. 记录真实的需求、受影响的客户端配置和当前缺陷。
2. 确认目标 **Minecraft Java 26.2 / Fabric** 的明确支持，核对已存在的 Sodium / Iris 版本。
3. 核查作者来源、许可、依赖链、已知安全问题。
4. 在三个客户端分别测试启动、进服、加载材质和光影。
5. 通过相同地图、分辨率和渲染距离比较平均 FPS、1% low、内存与日志。
6. 新增依赖要**固定版本**，在 CI 和本地验证，保留能回滚的旧构建。
7. 发布前更新三套发行指南与 Credits，明确任何功能差异。

## ATRIUM 的边界

ORIGO 是深圳 ATRIUM 首期单站点部署的**Minecraft 服务模块**。公网隧道、Windows 主控、NAS 数据区、Agent 权限和服务器备份将另设工程文档，不应与客户端 Mod 配置混淆。任何管理员凭证、云隧道密钥、世界私有备份不得加入公开仓库。
